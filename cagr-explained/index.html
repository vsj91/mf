CAGR Explained: What Annualized Return Shows—and Hides

CAGR is useful because it converts start and end values over multiple years into one annualized growth rate. It is also easy to over-trust because the smooth number hides everything that happened in between.

Written by: Vinay S Jain, creator of PlanSIP   •   Last reviewed: 18 August 2026

The idea behind CAGR

If ₹1,00,000 becomes ₹1,61,051 over five years, the equivalent compounded annual growth rate is about 10% a year. The actual yearly returns did not need to be exactly 10%.

CAGR is not an average of yearly returns

Simple averaging ignores compounding. A +50% year followed by -50% does not bring you back to the starting value; ₹100 becomes ₹150 and then ₹75.

What CAGR hides

  • How deep interim losses were.
  • How volatile the journey was.
  • Whether most gains came in a short period.
  • Investor cash-flow timing.

CAGR versus SIP investor return

A lump-sum CAGR measures a start value and end value. SIPs involve many cash flows at different dates, so investor-return measures such as XIRR are conceptually more appropriate for actual transaction histories. PlanSIP's historical SIP Replay instead simulates units purchased through available NAV observations and reports the resulting history.

How PlanSIP uses it

When enough NAV history exists, annualized returns can help compare the same look-back period across funds. PlanSIP pairs returns with consistency, volatility, drawdown and available history rather than treating CAGR alone as a winner selector.
